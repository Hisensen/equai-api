字段必填允许值说明
kind是text / image / reference决定素材校验方式。

video_audio_flags否例如 1,0仅用于 reference。按 videos 的上传顺序对应：1 保留该参考视频的声音，0 忽略；不传时默认全部保留。

多参考视频

直接使用可重复的 images、videos 和 audios 文件字段，不需要额外的类型数组。

images=@person.png→<Picture 1>
videos=@motion.mp4→<Video 1>
audios=@voice.wav→<Audio 1>
编号与限制图片、视频、音频分别按各自的上传顺序编号。例如第 2 张图片是 <Picture 2>，第 1 个视频仍是 <Video 1>。图片最多 9 张、视频最多 3 个、音频最多 3 个，全部合计最多 12 个且不超过 512MB。
Subject 不是文件字段<Subject 1> 是你在提示词中自行定义的语义名称，服务端不会自动创建 Subject。需要明确写成“<Subject 1> 是 <Picture 1> 中的女子”。文件名只用于上传，不参与提示词匹配。

Python 完整格式：3 张图片＋2 个视频＋1 个音频

最关键的 Python 规则files 必须是列表，每个元素都是 (字段名, (文件名, 文件对象, MIME))。同一个字段可以重复；不要写成字典，否则多张 images 会互相覆盖。
requests · 可直接复制运行的多参考示例
import os
import uuid
import requests

BASE_URL = ""
API_KEY = os.environ["EQUAI_API_KEY"]

prompt = """subject_definitions:
<Subject 1> 是 <Picture 1> 中的年轻女子，保持面部和服装一致。
<Subject 2> 是 <Picture 2> 中的母亲，保持面部和服装一致。
<Subject 3> 是 <Picture 3> 中的父亲，保持面部和服装一致。

detailed_description:
<Subject 1> 在院子中奔跑，动作参考 <Video 1>，
镜头运动参考 <Video 2>，环境中播放 <Audio 1> 的声音。"""

with (
    open("woman.png", "rb") as picture_1,
    open("mother.png", "rb") as picture_2,
    open("father.jpg", "rb") as picture_3,
    open("action.mp4", "rb") as video_1,
    open("camera.mp4", "rb") as video_2,
    open("ambient.wav", "rb") as audio_1,
):
    # 顺序决定编号：三个 images 分别是 Picture 1/2/3；
    # 两个 videos 分别是 Video 1/2；audios 从 Audio 1 重新编号。
    files = [
        ("images", ("woman.png", picture_1, "image/png")),
        ("images", ("mother.png", picture_2, "image/png")),
        ("images", ("father.jpg", picture_3, "image/jpeg")),
        ("videos", ("action.mp4", video_1, "video/mp4")),
        ("videos", ("camera.mp4", video_2, "video/mp4")),
        ("audios", ("ambient.wav", audio_1, "audio/wav")),
    ]
    data = {
        "kind": "reference",
        "prompt": prompt,
        "duration": 15,
        "ratio": "16:9",
        "title": "merchant-order-20260830-001",
        "seed": 0,
        # 对应 Video 1、Video 2：保留第一个视频声音，忽略第二个。
        # 如果两个视频声音都要保留，可以不传此字段。
        "video_audio_flags": "1,0",
    }
    response = requests.post(
        f"{BASE_URL}/v1/videos/1080p",  # 改成 /720p 即创建 720P
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Idempotency-Key": str(uuid.uuid4()),
        },
        data=data,
        files=files,
        timeout=600,
    )

response.raise_for_status()
task = response.json()
print(task["id"], task["status"])
Python 中的上传项提示词中的名称说明
第 1 个 images<Picture 1>woman.png
第 2 个 images<Picture 2>mother.png
第 3 个 images<Picture 3>father.jpg
第 1 个 videos<Video 1>video_audio_flags 中第 1 位与它对应
第 2 个 videos<Video 2>video_audio_flags 中第 2 位与它对应
第 1 个 audios<Audio 1>音频单独从 1 开始编号
常见错误不要把字段写成 picture_1、video_1 或 uploads；不要把多个文件放进 Python 字典；有 2 个视频时，video_audio_flags 若传入就必须正好有 2 位。参数或素材校验失败返回 422，不会扣积分。

PY

Python 调用

三个创建函数分别对应 720P、1080P 和 2K，不需要额外传清晰度参数。

requests · 三种模式
import os
import uuid
import requests

BASE_URL = ""
API_KEY = os.environ["EQUAI_API_KEY"]

def _create_video(path, kind, prompt, files=None, extra_fields=None, **options):
    data = [
        ("kind", kind),
        ("prompt", prompt),
        ("duration", options.get("duration", 15)),
        ("ratio", options.get("ratio", "16:9")),
        ("title", options.get("title", "merchant order")),
        *(extra_fields or []),
    ]
    response = requests.post(
        f"{BASE_URL}{path}",
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Idempotency-Key": options.get("order_id", str(uuid.uuid4())),
        },
        data=data,
        files=files or [],
        timeout=600,
    )
    response.raise_for_status()
    return response.json()

def create_720p(kind, prompt, **options):
    return _create_video("/v1/videos/720p", kind, prompt, **options)

def create_1080p(kind, prompt, **options):
    return _create_video("/v1/videos/1080p", kind, prompt, **options)

def create_2k(kind, prompt, **options):
    return _create_video("/v1/videos/2k", kind, prompt, **options)

# 1. 文生 720P
text_task = create_720p("text", "电影感城市夜景")

# 2. 首尾帧 1080P
with open("first.png", "rb") as first, open("last.png", "rb") as last:
    image_task = create_1080p("image", "人物自然完成动作", files=[
        ("first_frame", ("first.png", first, "image/png")),
        ("last_frame", ("last.png", last, "image/png")),
    ])

# 3. 多参考 1080P：同一素材类型的文件字段可以重复
with open("person.png", "rb") as person, open("motion.mp4", "rb") as motion:
    reference_task = create_1080p("reference", "保持人物一致并参考视频运镜", files=[
        ("images", ("person.png", person, "image/png")),
        ("videos", ("motion.mp4", motion, "video/mp4")),
    ])

# 4. 文生 2K
ultra_task = create_2k("text", "电影感山谷航拍，云层缓慢移动", duration=15)

print(ultra_task["id"], ultra_task["status"])

轮询示例

Python · 断线自动恢复，每 15 秒查询
import time
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

session = requests.Session()
session.mount("https://", HTTPAdapter(max_retries=Retry(
    total=8, connect=8, read=8, status=8, backoff_factor=1,
    status_forcelist=(429, 500, 502, 503, 504),
    allowed_methods=frozenset({"GET"}),
)))

task_id = reference_task["id"]
while True:
    try:
        response = session.get(
            f"{BASE_URL}/v1/videos/{task_id}",
            headers={"Authorization": f"Bearer {API_KEY}"},
            timeout=30,
        )
        response.raise_for_status()
        result = response.json()
    except requests.RequestException as exc:
        print(f"查询暂时断线，原任务仍在运行：{exc}")
        time.sleep(15)
        continue
    if result["status"] == "completed":
        video_url = result["artifacts"][0]["download_url"]
        print("download:", video_url)
        break
    if result["status"] in {"failed", "cancelled"}:
        raise RuntimeError(result.get("error") or result.get("message"))
    time.sleep(15)

HTTP

错误码

状态码含义处理方式
401API Key 缺失、错误或已撤销检查 Bearer 格式；必要时在商家控制台创建新 Key。
402积分不足联系管理员充值；充值后有效 Key 自动恢复。
403账户待开通或已暂停联系管理员开通或解除暂停。
404任务不存在检查任务 ID；商家之间的数据严格隔离。
409任务状态不允许该操作例如已完成任务不能取消。
413单文件或整次请求素材合计超过 512MB压缩或减少素材后重新提交。
422字段、素材数量或类型错误根据响应中的 detail 修正请求；不扣积分。
429商户已有 4 个未结束任务等待已有任务完成后重试，并保留原 Idempotency-Key。
